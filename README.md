# Register-JWT-Auth

In this project I have created a fullstack app where with React and Node js I will authenticate users and have a login and register page.
If a user is not registered, they can register and then login. After they log in, they will have access to the information of the page.
If they are not logged in, they cannot have access to the page. If the user has not registered, they need to register fisrt and then log in and with JWT token, it will make sure that the information match.

The main focus of this project is to learn Authenticating the users with JWT token using React and Node and for the backend using Mysql.
